# Goblin

**Goblin** extends [GAPI](https://github.com/goppydae/gapi) with distributed orchestration capabilities.

## Features

- **Cluster Membership**: Serf-based discovery.
- **Consensus**: Raft-based leader election.
- **Distributed Events**: Unified event bus across the cluster.
