# Reference

The command reference for `goblind` and `goblinctl`.

`cli-reference.md` here is hand-written and is the last of its kind in
this repository. It is replaced by output generated from the cobra command
tree once the generator can be built, which needs the kernel's `pkg/docsgen`
in a release tag. It is kept until then because deleting a reference before
its replacement exists leaves the repository with none.
