# User Guide

Running Goblin: what it is, and how to bring a cluster up.

Installation and configuration guides are not here yet. Goblin's install
and config surface is not settled, and a page describing an unsettled
surface is worse than an absent one - it reads as documentation to every
reader who finds it, and outlives the notice that says it should not.
